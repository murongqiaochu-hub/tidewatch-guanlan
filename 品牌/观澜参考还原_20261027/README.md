# 观澜标志资源

本目录保存 Tidewatch 观澜的手工矢量标志及其预览、校验和导出工具。当前图形是根据提供的视觉参考重新绘制的近似稿，不是原始可编辑设计源文件；几何和颜色应由品牌事实源统一维护，不要单独改写生成文件。

## 文件

- `logo.mjs`：路径几何、颜色、DOM 组件与静态 SVG 序列化。
- `duotone.svg`、`mono.svg`、`reverse.svg`：双色、单色与反白版本。
- `preview.html`、`preview.png`、`showcase.html`、`showcase.png`：本地预览与展示图。
- `生成预览.mjs`、`导出展示图.mjs`：按现有矢量母版重建预览。
- `验证.mjs`、`验证结果.json`、`展示图验证.json`：本目录资源的静态与浏览器校验记录。
- `SHA256SUMS`、`范围核对.json`：本目录文件的完整性和范围记录。

## 规范

- 深青 `#064852`、玉绿 `#19A98C`、反白 `#FFFFFF`。
- 各版本使用 `viewBox="0 0 544 544"`，等比缩放；双色/单色适用于浅色背景，反白适用于深色背景。
- 与可见“观澜”字标并排时，将图形设为装饰性；独立图形应提供可访问名称。单色内联组件使用宿主 `color`。
- 推荐尺寸不低于 24px；小尺寸避免非整数缩放或压缩。
