## 当前限制

- 平台 Dockerfile/Compose 与反代样例已写入仓库，并在 NAS 宿主真实 Docker 上完成构建、启动、健康检查、重启持久性与 Compose 路径验证（开发容器本身没有 Docker）。
- **已验证**：Caddy 2.10.2 + 内部 CA 的隔离 HTTPS 反代路径（健康、登录、Secure Cookie、认证接口、错误 Origin 拒绝）。公网域名/ACME 证书签发与续期、Nginx、真实 Figma/macOS、编码器挂载、基础镜像 digest 与第三方材料仍未完成；因此仍不等于已验证的生产部署。
- `原生编码器/Dockerfile` 仅用于构建编码器产物，不会随平台镜像一起打包预览能力。
- 全量自动化测试目前未达到发布门槛；本地演练或定向测试通过不等于完整测试通过。
- 本文档不提供生产切换、数据迁移或发布授权。任何此类工作须遵循独立授权与恢复门槛。
